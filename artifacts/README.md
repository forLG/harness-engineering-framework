# Artifacts

This directory is ignored by default and is reserved for local evidence that is worth keeping during human-supervised Codex work.

Use it for:

- Test output that explains a failure or fix.
- Screenshots needed for UI review.
- Logs or traces that make a decision reproducible.
- Packaging or manual validation notes.

Avoid storing secrets, credentials, private user data, sensitive screenshots, or noisy command output.

Suggested local names:

- `artifacts/test-*`
- `artifacts/screenshots/`
- `artifacts/logs/`
- `artifacts/traces/`
